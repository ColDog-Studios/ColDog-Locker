## Current Status

ColDog Locker is pre-release software. The CLI, terminal UI, and Avalonia GUI are built into Windows, Linux, and macOS packages, but native validation is incomplete. See [Platform and Storage Support](platform-support.md) before installing. Windows and macOS packages are unsigned and may trigger platform security warnings.
